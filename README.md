# CSC Web Dev Interview Challenge

1. Clone the repo
   
   ```
   git clone git@github.com:BoscoZhangers/CSC-Interview-Challenge.git
   ```

2. Create your own branch

   ```
   cd CSC-Interview-Challenge && git checkout <firstname-last-name>
   ```

3. Ensure you are on your new branch

   ```
   git branch 
   ```

4. Install npm (you may need to update your npm version)
   
   ```
   cd interview-app && npm install
   ```
   
5. Run it locally (go to http://localhost:5173 in your browser)
   
   ```
   npm run dev
   ```

6. Push your changes
   ```
   git add . && git commit -m "my submission" && git push
   ```
