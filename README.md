# CSC Web Dev Interview Challenge

1. Clone the repo
   
   ```
   git clone git@github.com:BoscoZhangers/CSC-Interview-Challenge.git
   ```

2. Install npm
   
   ```
   cd CSC-Interview-Challenge && cd interview-app && npm install
   ```
   
3. Run it locally (go to http://localhost:5173 in your browser)
   
   ```
   npm run dev
   ```
